# 릴스메이커 모바일

사진과 음성(TTS)으로 휴대폰 안에서 바로 릴스(세로 영상, 1분 이내)를 만드는 웹앱이에요.
사진·음성·영상은 휴대폰 밖으로 나가지 않아요.

- 사용: 안드로이드 크롬으로 접속 → 메뉴 ⋮ → **홈 화면에 추가**
- 만든 사람: 정은영 (더드림교육문화센터)
- 사용한 공개 소프트웨어: sherpa-onnx (Apache-2.0), SenseVoice 모델 (FunASR 모델 라이선스), Mediabunny (MPL-2.0), Pretendard · Black Han Sans · Jua · Do Hyeon (SIL OFL 1.1)
